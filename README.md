# Kalkulator Sederhana

Simple calculator built with **Java Swing**.

Project ini merupakan aplikasi kalkulator sederhana dengan tampilan GUI (Graphical User Interface) yang dibuat menggunakan bahasa pemrograman Java dan Java Swing.

## Features

| Feature        | Description                                |
| -------------- | ------------------------------------------ |
| Addition       | Penjumlahan `+`                            |
| Subtraction    | Pengurangan `-`                            |
| Multiplication | Perkalian `*`                              |
| Division       | Pembagian `/`                              |
| Delete         | Menghapus angka terakhir `DEL`             |
| Clear          | Menghapus dan mereset kalkulator `C`       |
| Equal          | Menampilkan hasil perhitungan `=`          |
| GUI            | Tampilan kalkulator menggunakan Java Swing |

## Technologies

| Technology | Usage                    |
| ---------- | ------------------------ |
| Java       | Programming language     |
| Java Swing | Graphical User Interface |
| AWT        | UI components and events |

## How to Run

### 1. Requirements

* Java Development Kit (JDK) sudah terinstal.
* Terminal atau Command Prompt.

### 2. Compile the Program

Buka terminal pada folder proyek, lalu jalankan perintah berikut:

```bash
javac Kalkulator.java
```

### 3. Run the Program

Setelah proses kompilasi berhasil, jalankan:

```bash
java Kalkulator
```
